The 5 Guards

Direct explanations: problem, solution, and run command.

1

AI Slop Guard

ai-slop-guard/ →

Problem: AI tools frequently delete critical platform guards (Platform.isIOS), swallow exceptions in empty catch blocks, or re-implement existing utils with multi-line boilerplate.

Solution: Inspects git diffs before merging and flags any dropped platform boundaries, security checks, or suppressed errors.

How to run: Run node scripts/scan-diff.cjs main to scan the incoming diff.

2

AI Fingerprint Scrubber

ai-fingerprint-scrubber/ →

Problem: AI litters comments with decorative emojis, conversational narratives ("Let's go ahead and..."), and obvious echo comments repeating the method name.

Solution: Removes emoji noise, prunes redundant echo comments, and enforces the rule: "Code explains WHAT, Comments explain WHY".

How to run: Run node scripts/scrub-fingerprints.cjs to sanitize comments across your project.

3

Phantom Package Sentinel

phantom-package-sentinel/ →

Problem: AI models hallucinate non-existent package names, which attackers then register on npm and PyPI to harvest environment secrets and API keys.

Solution: Verifies package registration age (<30 days flagged), download thresholds, and repository linkage before dependencies are installed.

How to run: Run node scripts/audit-manifest.cjs <package-name> before running install commands.

4

Orphan Dependency Guard

orphan-dependency-guard/ →

Problem: AI adds dependencies for rapid prototyping, refactors the code later, and leaves unreferenced packages abandoned in package.json or pubspec.yaml.

Solution: Audits all project imports against manifest declarations, highlights zero-reference packages, and estimates dead bundle weight.

How to run: Run node scripts/scan-orphans.cjs. Dependencies are never pruned without explicit confirmation.

5

Mobile Revenue Guard

mobile-revenue-guard/ →

Problem: AI misses the Google Play 72-hour purchase acknowledgement requirement, writes plain-text entitlement flags to shared preferences, or forgets server-side verification on rewarded ads.

Solution: Audits client billing loops, requires hardware-backed keystore/keychain entitlement storage, and validates StoreKit 2 / Google Play purchase lifecycles.

How to run: Review invariants in mobile-revenue-guard/SKILL.md prior to production app builds.
