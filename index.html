The 5 Guards

Plain English explanations: problem, solution, and run command.

1

AI Slop Guard

ai-slop-guard/ →
Problem
AI coding tools silently delete existing safety checks (auth guards, platform boundaries), swallow crashes in empty catch {} blocks, or write bloated boilerplate instead of reusing existing helpers.
Solution
Scans incoming git diffs before merging to detect dropped safety invariants, swallowed exceptions, and duplicate code.
Run
node scripts/scan-diff.cjs main
2

AI Fingerprint Scrubber

ai-fingerprint-scrubber/ →
Problem
AI litters your code with decorative emoji clutter (🚀 ✨ 🔒), chatty tutorial talk ("Let's go ahead and..."), and robotic echo comments that redundantly state the obvious.
Solution
Detects and scrubs emoji noise, tutorial prose, and obvious comments—enforcing clean, professional, human-written code hygiene.
Run
node scripts/scrub-fingerprints.cjs
3

Phantom Package Sentinel

phantom-package-sentinel/ →
Problem
AI hallucinates non-existent package names. Attackers register those exact names on npm/PyPI with malicious scripts to steal .env files and API keys during install.
Solution
Pre-flight verification that audits package registration age, download thresholds, and repository linkage before any package manager touches your machine.
Run
node scripts/audit-manifest.cjs <package>
4

Orphan Dependency Guard

orphan-dependency-guard/ →
Problem
AI installs libraries for prototyping, refactors the code later to use another approach, but forgets to remove the unused packages—leaving dead bloat in package.json or pubspec.yaml.
Solution
Audits project imports against manifest declarations, flags packages with zero code references, and safely prunes deadweight dependencies with your confirmation.
Run
node scripts/scan-orphans.cjs
5

Mobile Revenue Guard

mobile-revenue-guard/ →
Problem
AI writes fragile monetization code—missing Google Play's 72-hour purchase acknowledgement (triggering auto-refunds), storing paid unlocks in unencrypted storage, or omitting SSV on rewarded ads.
Solution
Enforces Google Play purchase acknowledgement, Apple StoreKit 2 verification, hardware-backed encrypted storage, and fraud-proof rewarded ad checks.
Run
mobile-revenue-guard/SKILL.md
