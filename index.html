The 5 Guards (Explained in Normal Words)

No complicated theory. Just the problem, the fix, and how to run it.

1

AI Slop Guard

ai-slop-guard/ →
  • Problem: AI tools frequently delete important platform checks (Platform.isIOS), swallow errors in empty catch blocks, or write 40 lines of boilerplate for simple 1-line tasks.
  • Solution: It inspects git diffs before merging and instantly alerts you if any platform guards, security checks, or error handlers were silently dropped.
  • How to run: Run node scripts/scan-diff.cjs main to scan your incoming pull request.
2

AI Fingerprint Scrubber

ai-fingerprint-scrubber/ →
  • Problem: AI litters your source code with tacky emojis (🚀 ✨ 🔒), podcast-style narrative comments ("Let's go ahead and..."), and repeats the obvious.
  • Solution: It strips decorative emojis from comments, deletes useless echo comments, and enforces the rule: "Code explains WHAT, Comments explain WHY".
  • How to run: Run node scripts/scrub-fingerprints.cjs to make your code look clean and human.
3

Phantom Package Sentinel

phantom-package-sentinel/ →
  • Problem: AI models often hallucinate fake package names that attackers then register on npm and PyPI to steal your API keys and cloud credentials.
  • Solution: It checks the registry for package age (<30 days is a red flag), download counts, and verified source code before any install script can run.
  • How to run: Run node scripts/audit-manifest.cjs <package-name> before running install.
4

Orphan Dependency Guard

orphan-dependency-guard/ →
  • Problem: AI installs packages for quick experiments, refactors the code later, but leaves deadweight packages abandoned in your package.json or pubspec.yaml.
  • Solution: It scans all source files in your project, finds declared packages with 0 imports, and tells you exactly how many megabytes they waste.
  • How to run: Run node scripts/scan-orphans.cjs. It asks your permission before removing anything.
5

Mobile Revenue Guard

mobile-revenue-guard/ →
  • Problem: AI misses Google Play's 72-hour purchase acknowledge deadline (Google auto-refunds users while they keep the item), or saves VIP status in unencrypted storage.
  • Solution: It audits client billing code, enforces hardware keystore/keychain storage, and prevents double-claim exploits on rewarded ads.
  • How to run: Follow the 6 monetization invariants in mobile-revenue-guard/SKILL.md before app store release.
